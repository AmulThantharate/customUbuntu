# Security Policy

NebulaOS is a live/installable operating-system project. Until a stable release is published, security support is best-effort.

## Reporting a vulnerability

Do not publish credentials, private keys, or exploitable proof-of-concept details in a public issue. Use GitHub's private vulnerability reporting when enabled for this repository, or contact the project maintainer privately.

Include the affected version or commit, component, reproduction steps, security impact, and suggested mitigation if known.

## Release security

Release artifacts should include SHA-256 checksums. Release signing keys must never be committed to this repository.
