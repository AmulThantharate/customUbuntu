# Day 11 — NebulaOS Branding

## Goal

Give the Arch build a clear NebulaOS identity.

## Tasks

1. Configure the hostname and OS identity.
2. Add the NebulaOS release information.
3. Configure the login/MOTD presentation.
4. Add visual branding only after the functional system is stable.
5. Keep branding files inside the Arch profile.

## Expected result

The live Arch system identifies itself clearly as NebulaOS without changing the underlying Arch build workflow.
