# Day 6 - XFCE desktop branding

## Goal

Make the desktop feel like NebulaOS rather than an unmodified Ubuntu desktop.

## Learn

- XFCE
- LightDM
- GTK themes
- desktop defaults
- `/etc/skel`

## Task

Plan and implement:
- wallpaper
- default terminal
- desktop name
- panel/menu defaults
- login screen branding

Do not modify upstream system files unnecessarily; prefer configuration in the appropriate include or hook location.

## Done when

A fresh live boot visibly presents NebulaOS branding on the desktop and login screen.
