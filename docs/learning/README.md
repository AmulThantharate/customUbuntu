# NebulaOS 14-Day Learning Path

This directory is the hands-on learning track for building NebulaOS with live-build.

## How to use

Complete one day at a time. Each day contains:
- concepts to understand
- commands to run
- a practical task
- a completion checklist

The learning path uses the real repository structure. Do not skip validation or clean-build steps.
