# Day 7 - DevOps tooling

## Goal

Build a useful DevOps workstation without turning the base image into an unmaintainable package dump.

## Learn

Separate:
- base operating system
- desktop
- installer
- optional DevOps tooling

Potential tooling categories:
- Git
- curl/wget
- jq
- SSH
- kubectl
- Helm
- OpenShift `oc`
- Terraform

## Task

Classify each tool as base, optional, or future module. Add only the tools justified for the first release.

## Done when

You can explain why each production image package exists.
